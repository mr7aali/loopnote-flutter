# TaskLoop

A Flutter app for managing your daily tasks, notes, and work assignments —
all in one organized place.

## Features

- 📝 Personal notes with optional reminder notifications
- ✅ Unified task list: your own tasks + tasks assigned to you by others
- 👥 Assign work to teammates and track completion status in real time
- 🔔 Smart notifications for due dates, overdue tasks, and status changes
- 📴 Offline-first with automatic sync
- 🌓 Dark mode, modern UI

## Tech Stack

Flutter · Riverpod/Bloc · Firebase (Auth, Firestore, Cloud Functions, FCM)
