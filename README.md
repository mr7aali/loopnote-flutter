# Loop Note

A Flutter app for managing daily tasks, notes, reminders, and assigned work in one organized place.

## Features

- Personal notes with optional reminder notifications
- Unified task list for your own tasks and assigned work
- Team task assignment with real-time completion tracking
- Smart notifications for due dates, overdue tasks, and status changes
- Offline-first foundation with future sync support
- Modern light theme with Fresh Teal branding

## Tech Stack

Flutter, Firebase, and a future state management layer such as Riverpod or Bloc.

## Status

In development - MVP phase.
